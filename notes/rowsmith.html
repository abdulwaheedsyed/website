One workspace for every database

I wanted a solid replacement for Adminer and DBeaver: something with the best of both, plus the features I kept finding myself without.

They are good at different things. Adminer is light — a single PHP file you drop on a server and open in a browser. DBeaver goes deep — nearly any database, with a full set of tools for each. Rowsmith tries to keep both: a self-hosted web workspace, as easy to reach as Adminer, for MySQL, MariaDB, PostgreSQL with PostGIS, SQL Server, Oracle, MongoDB, BigQuery and SQLite, shipped as a single Go binary with the web app built in.

One interface, many engines

A common driver interface covers browsing, filtering, editing, running SQL, EXPLAIN plans, process lists, variables and users. Each engine adds only what it actually supports. Every driver is pure Go, so there is no Oracle Instant Client or Microsoft ODBC to install.

What I added on top

Roles and sharing, so a team can use one connection with read, write or manage access, and viewers stay read-only. Shareable links to a query, with comments on any line. Scheduled queries that email their result as Excel, CSV or JSON, post to Slack, Teams or a webhook, or alert only when something changes. And migration between servers and engines — MySQL to PostgreSQL, SQL Server to MySQL, MongoDB to SQL and back — with every column's type mapped for review and the copy checked value by value.

Secrets that stay secret

Connection passwords, SSH keys, TLS keys and API keys are envelope-encrypted before they touch disk, and they are never sent back to the browser. SSH tunnels, including chains of jump hosts, run inside the server process, so reaching a private server needs no extra software. New host keys are approved once; changed ones are rejected.

Rails for production

Statements are classified before they run. On a production connection, anything that might modify data asks for confirmation, and DROP, TRUNCATE, or a DELETE or UPDATE without a WHERE always does. Every data-modifying query lands in an audit trail: who, when and from where.

An assistant on your own terms

You can ask for a query in plain words, or have one explained, fixed or made faster. It runs on your own Anthropic, OpenAI or OpenRouter key, or on a model you host with Ollama. It reads the schema, never changes data, and only sees rows if you let it.

It is early, but all eight engines, the tunnels, the vault, migration and the assistant are working today.
